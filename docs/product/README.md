# product

## What is this directory?

Qianqian 的产品语义权威：产品是什么、当前播放产品的真实范围。

## What belongs here?

- `product.md` — 产品 stable truth：定位、原则、边界、non-goals。
- `player-mvp.md` — 当前播放产品范围：已具备的播放行为、application 职责、
  尚未开始的部分。

## What does not belong here?

- 架构 / 契约 / 构建内容（在 [../architecture/](../architecture/)、
  [../contracts/](../contracts/)、[../development/](../development/)）；
- 未来愿望清单（产品只记录 current truth 与已授权方向）。

## What should I read first?

产品任务先读 `product.md`；播放产品范围问题读 `player-mvp.md`。
