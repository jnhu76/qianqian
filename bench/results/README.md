# Benchmark Results

Layout:

```text
bench/results/
  README.md             this file
  schema.json           field contract for result documents
  songcore-v1/          SongCore ABI v1 machine authority tree (fail-closed
                        --check; see tests/songcore/README.md)
  common-formats/       Common Formats compatibility summary
  avfilter-minimize/    DSP capability closure summary (capability intent,
                        dependency provenance, shipping size, verdict)
  runs/                 UNTRACKED local runs (bench/results/runs is
                        gitignored)
```

## Tracked vs generated

The only tracked results are the ones a gate depends on. Everything else is
regenerated by its owning script from stable inputs (corpus + build +
manifests):

| Path | Status |
|---|---|
| `bench/results/songcore-v1/` | tracked — SongCore authority, validated read-only by `tests/songcore/regression.py --check` |
| `bench/results/common-formats/` | tracked — Common Formats compatibility summary |
| `bench/results/avfilter-minimize/` | tracked — DSP/SRC capability closure summary |
| `bench/results/runs/**` | untracked — every local run |

Historical experiment result trees (WASM ladder, PCM-pipeline stages,
benchmark baselines, minimization ladder intermediates) are regenerated by
their experiment scripts and are intentionally not committed. Git history
preserves past snapshots.
