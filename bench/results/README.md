# Benchmark Results

Layout:

```text
bench/results/
  README.md             this file
  schema.json           field contract for result documents
  songcore-v1/          SongCore ABI v1 machine authority tree (fail-closed
                        --check; see native/tests/songcore/README.md)
  common-formats/       Common Formats compatibility summary
  avfilter-minimize/    DSP closure capability summary (capability intent,
                        dependency provenance, shipping size, verdict) —
                        FROZEN reference, regenerable only by re-running the
                        DSP closure ladder (tools/dsp_closure.py)
  decode-baseline/      native decode performance baseline (decode core vs
                        SongCore ABI: throughput, startup, per-read latency,
                        block sweep; regenerated by
                        tools/measure_decode_baseline.py from ≥3 full runs)
  wasm-summary.json     WASM viability result (durable machine summary;
                        see docs/research/wasm.md)
  runs/                 UNTRACKED local runs (bench/results/runs is
                        gitignored)
```

## Tracked vs generated

The only tracked results are the ones a gate depends on or that serve as
the final size/closure reference. Everything else is regenerated by its
owning script from stable inputs (corpus + build + manifests):

| Path | Status |
|---|---|
| `bench/results/songcore-v1/` | tracked — SongCore authority, validated read-only by `native/tests/songcore/regression.py --check` |
| `bench/results/common-formats/` | tracked — Common Formats compatibility summary (frozen reference) |
| `bench/results/avfilter-minimize/` | tracked — DSP closure capability summary (frozen reference; re-run `tools/dsp_closure.py` on an FFmpeg upgrade) |
| `bench/results/decode-baseline/` | tracked — native decode performance baseline (re-run `tools/measure_decode_baseline.py run` ×3 + `commit` to regenerate) |
| `bench/results/wasm-summary.json` | tracked — WASM viability summary (frozen reference) |
| `bench/results/runs/**` | untracked — every local run |

Historical experiment detail (WASM ladder, PCM-pipeline stages, benchmark
baselines, minimization intermediates) was archived; git history preserves
the raw trees. The retained summaries are the durable conclusions only.
